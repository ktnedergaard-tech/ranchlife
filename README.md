# Ranchliv 3D

Et 3D heste- og ranchspil på dansk, der kører direkte i browseren.

## Spil det

Åbn `index.html` i en browser, eller brug GitHub Pages-udgaven af repoet.

## Indhold

- Vælg at bo på ranchen eller i villa (med parthest på Søgården).
- Lav familien (mor, far og børn) og vælg dine dyr: heste, hunde, katte og kaniner i rigtige racer.
- Pas dyrene: fodring, strigling, mugning, dækken, fold og gåture.
- Rid i skridt, trav og galop, spring forhindringer på banen, i ridehallen og over stammer i skoven.
- Job som ridelærer (hold og eneundervisning, SMS fra elever, elever der rykker op), kontorjob eller gårdjob.
- Årstider, vejr, døgnrytme, naboer, stævner, butik og egne ridetimer.

## Styring

- **WASD / piletaster**: gå
- **E**: brug det, du står ved
- **Til hest**: W/S tempo, A/D styr, Mellemrum spring, F stå af
- **Kamera**: træk med musen, scroll for zoom, Q/R drejer

## Teknik

Én enkelt `index.html` uden build-trin. 3D med three.js r128 (`vendor/three.min.js`, MIT-licens).
Spillet gemmes i browserens `localStorage`.
